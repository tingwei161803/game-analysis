Overview / Henry (hryjosn)

Sleeping on the Couch?

A couples' texting quiz where a partner's line arrives with a countdown and every reply moves an anger meter: 1,008 hand-written questions across four editions, rounds that get longer when you answer well, one paid-for unsend per round, and a server that re-scores every round from the picks alone.

The seven dimensions

memoryTechnical Depth 7/10

A quiz, engineered like a product. The rules live in a small pure module shared by every mode — scoreRound, pressuredChange, stepChange in 0ma2uownr7jbx.js — and the client sends only the list of picks when a round ends (360jxnk-yjyfe.js, keepalive:!0), so the same arithmetic can be re-run on the server. Deck drawing takes its random source as a parameter (1b39y_5p_-gjb.js, r=Math.random), which is how the daily challenge becomes a seeded draw from the string daily:${e}:${t} through a hash and a small 32-bit generator (1penbu0-2u1xp.js, 0x6d2b79f5). Countdown timers are stored as absolute deadlines, and the seconds allowed grow with the amount of text to read (09wqhabreja_-.js, answerSecondsFor). Share cards are drawn on a canvas on the device and sound effects are synthesized from oscillators (2g29mqun0hkej.js, 1kb-rf1mcwrar.js createOscillator). The site runs Next.js 16.3.3 on Cloudflare through OpenNext, serves seven locales, subsets its two Chinese fonts per page, and recovers from stale chunks after a deploy (2xbrdu777y9d3.js, takeRecoveredStaleChunk). The ceiling is the genre: there is no simulation, no rendering problem and no hard algorithm, and every game page carries its whole question text in the HTML — 270 KB for the main game, 508 KB for the dating edition.

stadia_controllerGame Design 8.5/10

One number, and every rule is a comment on it. Anger starts mid-scale and differs by edition (09wqhabreja_-.js, {gf:50,bf:40,dating:65,her:50}); a good reply lowers it by 5, weaker ones raise it by 6, 18 or 26, a landmine ends the round, and letting the timer run out costs 22 — more than most wrong answers. Round length is the reward: the round stops at 8 questions if anger is 80 or more, at 10 if it is above 40, and runs to 12 otherwise (1b39y_5p_-gjb.js, e>=n.ROUND_MIN&&t>=n.FUME_ANGER), and the screen never shows how many are left. One message per round can be unsent for 12 points, offered only when it would not push the meter past 99 (360jxnk-yjyfe.js, <=f.UNSEND_CEILING). By this audit's count 35 of the 192 girlfriend-edition questions have no option that lowers anger, and the result page shows the best score the dealt deck allowed (bestPossibleAnger). The dating editions add a partner temperament rolled per round, with questions whose best reply depends on it (18o_2r373ihfb.js, misfitOptionIds). The writing carries it: each option has its own reply line. Reservations: the values are a single ladder — all 588 dating questions use the same five numbers — so no question weighs more than another, and the site's own statistics page reported a mean final anger of 75 and 41% of 573,363 rounds ending blocked.

securityBackend & Security 7/10

A real backend, and a privacy page that can be checked against the code. The client calls same-origin routes for statistics, duo and judge rooms, a weekly leaderboard, feedback, and an optional Google-only account with round sync and deletion (0ma2uownr7jbx.js, /api/me). Where the policy is checkable, the bundle agrees with it: session recording is not loaded on duo or judge paths (1kb-rf1mcwrar.js, clarityRecordsPath), the stored result is discarded after one day (3-24utn60ohi9.js, Date.now()-i>864e5), room codes are replaced before a page location reaches analytics (09wqhabreja_-.js, analyticsLocationOf), leaderboard posts carry a Turnstile token (3ep9joo73pia1.js, turnstileToken:), and error reporting is configured with userInfo:!1,cookies:!1 and no tracing (2xbrdu777y9d3.js). Missing paths return 404; HSTS, nosniff and a frame policy are set. Hygiene notes: the Content-Security-Policy is sent as report-only and allows 'unsafe-inline'; every option's score ships in the client (34r8bsq31k0-8.js, angerChange:-5), so server re-scoring proves a run is consistent, not that it was played blind; one plain GET of the statistics route returned question 1's option distribution without a round having been played; and two flows are not named on the privacy page as fetched — Sentry error reports, and a two-question survey that posts gender:t,intent:s to /api/probe. The server itself, its database and its rate limits could not be seen.

codeCode Quality 7/10

Only minified output is available, but Turbopack keeps module boundaries and export names, so the architecture can be read even though the source cannot. Rules are separated from views: constants and the ending ladder in one module (09wqhabreja_-.js, ENDING_LADDER), scoring in another (scoreRound), deck drawing in a third with its random source injected (drawRound, drawHellRun), and edition differences expressed as lookup tables instead of branches (EDITION_HAS_UNSEND, EDITION_ORDERED_CATEGORIES). Anything read back from localStorage is shape-checked before use and falls back to an empty value (3-24utn60ohi9.js, getResult; 1b39y_5p_-gjb.js, loadSeen). The duo and judge pages share one polling hook that backs off from 5 to 30 seconds, stops after 15 minutes and waits while the tab is hidden (1b39y_5p_-gjb.js, Math.min(1.5*o,3e4)). Analytics is a single object of named methods, not scattered calls (1kb-rf1mcwrar.js). The visible debt is in the views: the result screen, the game screen and the workplace quiz are each one very large component — roughly 1,900, 1,300 and 3,800 lines once beautified. Because the bundle is minified, naming inside functions, comments, types and duplication in the original source cannot be judged, and the score reflects structure only.

experimentTesting 3.5/10

No test file ships, no test runner is referenced in the bundle, and no CI for the game can be observed, so the score is capped as for the other shipped-artifact projects. What exists is the author's own account, in the making-of notes, of checks that run on the question bank: every bank is measured by a program that guesses from surface form alone — length, punctuation — with the stated target of doing no better than chance, and copy review by a language model is itself audited by planting known-bad sentences and discarding the batch if too many are missed (notes/how-a-question-is-written). The code is shaped for tests it does not show: pure scoring functions, an injected random source, a seeded daily deck. One thing is public and running: a separate MIT-licensed repository, hryjosn/sleep-on-the-couch-status, probes the home page, the result page and ads.txt every five minutes from GitHub Actions and opens an issue on failure. That is monitoring, not testing, but it is the only verification an outsider can inspect. None of the described checks can be read, run or counted from outside.

verifiedCompleteness 9/10

A finished, operated site, well past a single quiz. Four editions with separately written banks — girlfriend (192 questions), boyfriend (228), and both sides of a dating app (392 and 196) — and on top of them a free mode, an endless mode with a weekly leaderboard, a hard mode, a daily deck with streaks, a seasonal mode, a two-person guessing game by link, and a judge room where the partner rules on each reply. Two side quizzes (a workplace-message test and a daily general-knowledge round) and a separate daily-opinion app share the domain. After a round there is a share card in several formats, a review of every missed question with the reply that would have worked, and a personal history page. The interface exists in seven languages, the long-form notes in two; there is a privacy policy in both, an explicit licence for streamers, a contact form, a status page and a web app manifest. Sound has a mute toggle and reduced-motion is honoured. What is missing is small: no service worker, so the installable app does not work offline; the editions beyond the first exist only in Chinese and English; and no version number or changelog is shown to players.

emoji_objectsOriginality 8/10

The outer form is familiar: a scenario, a few replies, a verdict at the end is how many relationship quizzes work. What this project adds is in the mechanics. The round length answers to the meter, so a good player is questioned longer and a bad one is cut off. Silence is priced above most wrong answers. Some questions have no good reply and the result says so. A message can be unsent once, at a cost, mirroring the feature it imitates. The dating editions give the other person a temperament and reuse the same scenario with a different best reply for each. The judge room turns a solo quiz into something a partner rules on line by line. The material is the author's own: the About page says most questions are adapted from real conversations with identifying details changed, and that each of the seven language versions was rewritten instead of translated — the Korean one around K-drama and webtoon register. The statistics are also used in an unusual way, as an editing tool: answer distributions decide which questions get rewritten, while per-question numbers are deliberately kept off the public page.

Statistics kept as an editing tool

Most quiz sites publish their numbers because numbers are shareable. This one explains why it does not. The public statistics page stops at the category level; a note says a per-question block once existed and was removed because it had become 'a spoiler machine', and that the distribution for a question appears only in the review of a round you have just played.

The same note describes what the numbers are for. A wrong option chosen more often than the best one marks an unfair question; a best option chosen by nearly everyone marks a giveaway; both are fixed by rewriting the text, not the score. It also reports that after 21 boyfriend-edition answers were re-scored with no text change, the distributions of 14 followed the new answer within a week — players learn from the review page — and that timeout rate correlates with question length at about 0.6, which is why answer time now scales with reading length. These are the author's figures and cannot be checked from outside.

The line is firmer in the prose than in the artifact. Every option's score ships in the client bundle, and a single GET to the statistics route during this audit returned question 1's option distribution without a round being played. Neither is surprising for a game that runs in the browser, and neither exposes anything about a person; but a reader should know that the answer table is withheld by editorial choice on the pages, not by the protocol.

smart_toyAI-assisted development

The site states AI use in one place, and only for text. The note on how a question is written says a batch of boyfriend-edition lines was once handed to an external model for polishing and more than a third came back broken, because options were smoothed while the partner's replies were left answering lines nobody had said; and that the first layer of copy review is a language model, whose output is trusted only after it catches enough deliberately planted bad sentences. No tool or model is named. Nothing in the pages or the bundle says how the code was written, and there is no history to consult. A separate note says feedback text is treated as untrusted and 'not executed, not obeyed', which reads like guidance for an automated reader; that is inference, not a statement. robots.txt declares ai-train=no.

Verdict

A one-person quiz built and run like a product: a single well-chosen mechanic, four separately written question banks, seven languages, a real backend, and a privacy page that mostly survives being checked against the bundle. Its limits are the ones an outsider cannot get past — private source, unseen server, tests described but not shown — plus an unenforced CSP and a scoring ladder that treats every question alike.
